# Typography — incubating Tarium candidate

- **Lifecycle:** incubating
- **Materialization:** province
- **Host candidate:** Designarium
- **Sovereignty:** not yet earned

## Canonical object

Typefaces, type families, faces, letterforms, typographic systems, and type-design artifacts.

## Current home

Typography begins as a Designarium province. Writing systems remain Linguarium objects; font technology/shaping may project into Software Studies.

## Existing independent structure

Typeface, family, face, weight, width, contrast, axis, serif structure, terminal, counter, x-height, proportion, intended use, genealogy, historical school, critique, personal response.

## Promotion trigger

Reconsider sovereignty if the work accumulates substantial glyph construction, font engineering, variable axes, optical compensation, kerning systems, hinting, type history, actual font assets, original typefaces, specialized tooling, and enough theory that Designarium becomes structurally strained.

## Constitutional conclusion

Typography is important enough to incubate, not yet independent enough to secede.
