## Canonical object

Software as an object of descriptive, historical, taxonomic, and theoretical study.

## Core question

**What is software? What kinds exist? How did they emerge? How do their abstractions differ?**

## Native objects and relations

Programming language, paradigm, compiler, interpreter, operating system, database, GUI, distributed system, package manager, shell, build system, serialization format, protocol, runtime, library, framework, dependency, abstraction, execution model.

## Major proposed provinces

Languages, paradigms, operating systems, databases, interfaces, distributed systems, build/package ecosystems, protocols, software history, abstractions, generative/declarative systems.

## Boundary with Software Philosophy

Software Philosophy is normative: how Salvador's software ought to be constructed. Software Studies is descriptive, historical, taxonomic, comparative, and theoretical.

Salvador's generative/declarative theories may appear here as explicit theoretical contributions without turning the whole field into personal doctrine.

## Phenomenological layer

Programming experience, conceptual elegance, frustration, legibility, taste, and first-person interaction with software systems may be preserved separately from technical description.
