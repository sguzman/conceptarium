# Tarium Candidates

This directory contains **pre-sovereignty repository objects**.

A file here does not imply that a GitHub repository exists.

Canonical lifecycle state is recorded in [`registry/tarium-candidates.yml`](../registry/tarium-candidates.yml).

The constitutional promotion rules live in [`meta/tarium-sovereignty-and-lifecycle.md`](../meta/tarium-sovereignty-and-lifecycle.md).

The governing rules are:

> **Intensity admits a subject to consideration. It does not grant repository sovereignty.**

> **Creating the stub is cheap; creating the repository is expensive.**

Approved stubs have passed the sovereignty test in principle but remain uninstantiated. Incubating candidates remain provinces of another domain. Merged or rejected candidates remain preserved because their disposition is itself ontological knowledge.
