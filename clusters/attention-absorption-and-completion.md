# Attention, Absorption, and Completion

This cluster tracks how media objects become temporarily more or less available to attention, how unfinished objects remain cognitively open, and how changing appetite reshapes the media choice set.

## Active entries

- [Genre lock](../entries/genre-lock.md)
- [Closure pressure](../entries/closure-pressure.md)

## Core interaction

```text
current affective / cognitive appetite
        ↓
Genre lock
        ↓
matching works become highly admissible
        ↓
unfinished matching work becomes salient
        ↓
Closure pressure
        ↓
return / completion / deliberate abandonment
        ↓
possible closure
```

The two concepts are related but operate at different levels.

**Genre lock** is a state of the consumer:

> Which kinds of media are currently available to desire?

**Closure pressure** is a state of the consumer-object relation:

> Which unfinished object is still mentally open and making a claim on attention?

## Genre-lock branch

Genre lock should eventually connect to a broader theory of **media appetite**.

Candidate subordinate concepts:

- tone lock;
- aesthetic lock;
- mood-congruent selection;
- motivational admissibility;
- latent feature bundle.

These are not yet promoted.

The important current distinction is between a nominal genre label and the deeper bundle of features actually being sought.

For example:

```text
"science fiction"
may compress:
brooding atmosphere
+ dark story
+ high-contrast lighting
+ futurist urbanity
+ technological saturation
+ small embers of hope
```

## Closure-pressure branch

Closure pressure should eventually be compared with:

- completionism;
- backlog guilt;
- unfinished-task effects;
- FOMO;
- sunk-cost effects;
- need for closure.

The local concept should not be collapsed into any of these until the mechanisms are compared carefully.

Its distinctive formulation is:

> **There is still more of the object to absorb.**

That makes closure pressure partly experiential and epistemic rather than merely achievement-oriented.

## Open-object model

A useful shared abstraction is the **open object**:

```text
object entered
   +
object valued
   +
remainder represented
   ↓
object remains psychologically open
```

Closure pressure is one consequence of an open object.

Genre lock determines whether that object is currently appetitive enough to reactivate.

## Research frontier

Likely future concepts:

- **tone lock** — temporary narrowing around atmosphere or affective texture across genre boundaries;
- **media appetite** — state-dependent distribution of motivational access across representational forms;
- **open object** — an unfinished bounded object whose remainder remains cognitively represented;
- **deliberate closure** — terminating an open object by consciously abandoning rather than completing it;
- **absorption remainder** — the represented portion of an experience still felt to be unconsumed.

These should be promoted only if they begin doing independent analytical work.
