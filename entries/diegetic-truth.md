# diegetic truth

## Definition

**Diegetic truth** is what is actually the case inside a represented world, independent of who knows it, who reports it, or whether any character has access to it.

The distinction is:

~~~text
DIEGETIC TRUTH
what happened / what is true in-world

        ≠

NARRATOR INFORMATION SET
what the narrator can access

        ≠

EPISTEMIC STATE
what the narrator currently believes
~~~

A story can therefore support dramatic irony, unreliable narration, mystery, deception, and partial knowledge without giving up the idea that there is a determinate world state.

## Problem pressure

The canonical **Diegetization** entry already states the problem directly:

> A useful distinction is between what is true in the fictional world and what a particular narrator can know about it.

Once narration is forced to acquire an epistemic address, omniscience can no longer be treated as an undifferentiated channel. We need a world-side reference against which narrator access and belief can be evaluated.

Without that reference, “unreliable narrator” becomes vague because there is no explicit distinction between **world error** and **access limitation**.

## Core model

~~~text
diegetic world state
       ↓ determines
DIEGETIC TRUTH
       ↓ partially exposed through
narrator information set
       ↓ interpreted into
epistemic state
       ↓ expressed as
narration
~~~

## Claims and implications

The distinction is especially useful in stories that model information rigorously.

A narrator may be:

- **uninformed** — lacks access to relevant truth;
- **misinformed** — has false evidence;
- **mistaken** — misinterprets accessible evidence;
- **deceptive** — knows the truth but reports otherwise.

Those are different epistemic failures.

The concept also transfers naturally to simulations and games where a hidden world state exists independently of agent observations.

## Examples

### Unreliable narrator

A narrator says a door was locked because they sincerely believe it. Later evidence reveals it was unlocked. Diegetic truth and narrator epistemic state diverged.

### Mystery

The murderer is determined in-world before the detective knows the identity. The truth exists before it enters the detective’s information set.

### Simulation

A game simulation contains the true location of an NPC even though no player character currently observes it.

## Non-examples

A deliberately indeterminate fiction may not supply a single diegetic truth on every disputed proposition.

A symbolic or surreal event should not be forced into literal world-state semantics if the work intentionally refuses that ontology.

## Boundaries and failure modes

The concept can overformalize fiction.

Some works produce contradiction, multiple incompatible worlds, metafictional instability, or ontological ambiguity. In those cases, “diegetic truth” may itself be plural, local, or intentionally underdetermined.

The distinction is a tool, not a demand that every story behave like a database.

## Operationalization / evidence

For a narrative claim, separately record:

1. in-world truth status;
2. narrator access;
3. narrator belief;
4. narrator report.

This four-part split makes reliability failures much more precise.

## Relations

Diegetic truth is distinguished from both **Narrator information set** and **Epistemic state**. It is associated with **Diegetization**, which gives knowledge a situated route, and constrains **Causal legibility** by determining which causal account is actually true in the represented world.
