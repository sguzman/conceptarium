# Unused exit remains an exit

## Definition

A voluntarily unused escape route remains structurally significant. Refusing mobility is not equivalent to lacking mobility.

Optionality can affect power even when never exercised.

## Problem pressure

The thread needed to distinguish chosen embeddedness from trapped embeddedness. The decision not to leave does not eliminate the bargaining and psychological effects of being able to leave.

The broader thread was trying to preserve exceptional intellectual capacity without either converting it into jurisdiction over others or demanding that the person erase the ego that carries the capacity.

## Core model

~~~text
exit option exists
      + voluntarily unused
      ≠
no exit option
~~~

## Claims and implications

Dependency analysis should track credible exit capacity, not only observed staying behavior.

This entry belongs to the architecture of **psychic sovereignty, epistemic submission, and social non-domination**.

## Examples

### Clean example

A professional chooses to remain in a low-income communal setting while retaining money, credentials, and documents that permit immediate departure.

### Borderline example

A case in which similar outward behavior exists but the underlying motive, exit option, or constitutional status differs.

## Non-examples

Someone stays because legal, financial, geographic, or coercive barriers make exit realistically unavailable.

## Boundaries and failure modes

An exit that is formally available but practically catastrophic may not be a meaningful exit. Credibility matters.

## Operationalization / evidence

Track the concrete features named by the concept rather than inferring equivalence from appearances alone. For dependency claims, inspect credible exit and fallback options. For epistemic claims, inspect actual response to correction. For psychic-governance claims, distinguish internal desire from external imposition.
