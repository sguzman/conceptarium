# Procedural visual language

## Definition

A **procedural visual language** is a visual style whose coherence comes from reusable rules of construction.

Instead of making each object independently and trying to match the style afterward, the system uses recurring:

- primitives;
- proportions;
- deformations;
- assembly rules;
- material rules;
- silhouette rules;
- exaggeration patterns.

The resulting objects look related because they are generated by the same grammar.

## Problem pressure

The concept emerged from wanting generative modeling to produce more than random variation.

A generator can create thousands of technically different characters while having no visual identity.

The desired system should make outputs feel as if they belong to the same world even when no individual mesh was hand-authored.

The solution was to treat style as **grammar rather than surface treatment**.

## Language analogy

A language contains:

- vocabulary;
- syntax;
- productive rules;
- constraints;
- recognizable transformations.

The procedural visual analogy is:

```text
primitive vocabulary
      +
composition rules
      +
deformation rules
      +
style constraints
      ↓
many novel but related forms
```

## Temporal extension

The original entry emphasized **constructional grammar**: recurring primitives, proportions, deformations, assembly rules, and silhouette rules that make generated objects look as though they belong to one world.

The animation glossary adds a second branch:

```text
procedural visual language
        ├── construction grammar
        │     how forms are built
        │
        └── transition grammar
              how forms may move, transform,
              disappear, recur, and change state
```

This is a semantic broadening rather than a replacement. A procedural visual language can govern static construction, temporal transformation, or both.

When temporal rules become stable enough, they can be described more specifically as an **animation grammar**. When those rules appear to function as laws of the represented world rather than merely authorial tricks, the stronger concepts **ontologized transition grammar** and **coherent metaphysics of animation** become relevant.

## Why this is stronger than style transfer

Style transfer can make surfaces look similar.

A procedural visual language changes **how forms are built**.

Two characters can share a language even with different textures because:

- their limbs taper similarly;
- faces use related constructive volumes;
- joints obey the same segmentation logic;
- exaggeration follows the same grammar.

## Constructive visibility

One attractive version deliberately allows the construction process to remain visible.

Bodies can look assembled.

Geometry can be obvious.

This creates a style where procedural origin is not hidden but celebrated.

## Semantic expression

The language becomes especially powerful when semantic properties map into construction.

For example:

- age changes sag, curvature, proportions;
- profession changes posture and clothing assemblies;
- personality changes silhouette and stance;
- mood changes tension and gesture.

The goal is for characters to **carry their personality in their bodies**.

## Non-examples

Procedural visual language is not:

- one shader applied everywhere;
- a common color palette;
- random procedural geometry;
- low-poly style by itself;
- a collection of individually authored assets.

Those can participate in a language without constituting one.

## Failure modes

### Uniformity

Grammar becomes so strict that every object looks like a clone.

### Rule incoherence

Rules interact in ways that destroy recognizability.

### Surface-only style

The generator changes textures but not structural form.

### Semantic disconnect

Character properties do not meaningfully alter generated geometry.

## Operationalization

A useful test:

> Can a viewer recognize that two previously unseen generated objects belong to the same constructional world?

A stronger test:

> Can the viewer infer some semantic differences from geometry alone?

## Provenance

The recovered v0.1 lexicon defined it as:

> “Modeling system where forms are generated through reusable grammatical/compositional rules rather than one-off meshes.”

It developed alongside the primitive-vocabulary and declarative-modeling concepts.

## Open questions

- Which rules define a style strongly enough without eliminating variation?
- Can multiple visual dialects share one primitive vocabulary?
- How should procedural languages evolve without breaking old generated content?
