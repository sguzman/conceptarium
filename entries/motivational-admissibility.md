# motivational admissibility

## Definition

**Motivational admissibility** is the degree to which an option can presently enter the set of things a person can actually **start, sustain, or want**, rather than merely the set of things they judge to be good.

The distinction is:

~~~text
evaluative approval
        ≠
motivational access
~~~

A game can be admired, recommended, and perfectly suited in the abstract while still failing to cross the current entry threshold for action.

## Problem pressure

Genre lock was defined as **temporary admissibility narrowing**. That phrase implied a more general variable underneath the lock: media options differ in whether they are currently accessible to motivation.

Without this concept, “I know this is good but I cannot make myself care about it” gets flattened into simple dislike.

## Core model

~~~text
candidate object
      ↓
matches current appetite?
      ↓
expected reward / friction / mood fit
      ↓
MOTIVATIONAL ADMISSIBILITY
      ↓
start / continue
or
bounce / defer
~~~

## Claims and implications

Admissibility is not binary in reality; it can vary continuously.

It is also not identical to attention capacity. A person may have enough cognitive capacity for a work but no motivational access to it, or strong motivation but insufficient capacity.

The concept generalizes beyond media, but the present entry is anchored in media choice.

## Examples

### Clean example

A highly regarded fantasy RPG feels impossible to start during a period when only brooding science fiction feels motivationally accessible.

### Cross-domain example

A research paper is intellectually relevant but temporarily inadmissible because the researcher’s current attention is locked onto a different problem family.

### Borderline example

A person declines a game because they only have twenty minutes. That may be practical constraint rather than low motivational admissibility.

## Non-examples

Disliking an object on stable evaluative grounds is not the same phenomenon.

External prohibition also does not make an object motivationally inadmissible; it can remain intensely desired while practically unavailable.

## Boundaries and failure modes

The term should not become a euphemism for every failure to act. Practical constraints, anxiety, executive dysfunction, fatigue, and low reward expectation can all contribute and should be distinguished where relevant.

The concept names the **resulting access state**, not necessarily one cause.

## Operationalization / evidence

Compare stated evaluation, desire, initiation latency, abandonment rate, and sustained engagement across options.

A clean signature is high evaluative approval paired with repeated failure to initiate or sustain engagement until the appetite state changes.

## Relations

Motivational admissibility is part of **Media appetite**. It can be constrained by **Genre lock**, **Tone lock**, or **Aesthetic lock**, and it shapes **Mood-congruent selection** by determining which candidates are even viable choices.
