# open object

## Definition

An **Open object** is a bounded experience, project, or representational object whose relation to the person remains cognitively **unfinished and live**.

It is not enough that the object is technically incomplete. Thousands of unfinished things can disappear from attention.

An object is open when the mind still represents:

~~~text
what has been engaged
        +
what remains
        =
an incomplete whole that still matters
~~~

## Problem pressure

Closure pressure needed a way to distinguish ordinary incompletion from **live incompletion**.

The canonical entry repeatedly described unfinished games as “open” and said the pressure was object-specific: **that game is still open**.

The queue preserved Open object as the object-side concept complementary to Closure pressure, which names the pressure produced by the open state.

## Core model

~~~text
bounded valued object
      ↓
partial engagement
      ↓
remainder remains represented
      ↓
object stays cognitively live
      ↓
OPEN OBJECT
      ↓
possible closure pressure
~~~

## Claims and implications

An open object need not produce distress. It can remain pleasantly unfinished, inviting future return.

Closure pressure is one possible consequence when the open state becomes demanding.

The concept also generalizes beyond media to projects, research questions, collections, or skill progressions.

## Examples

### Clean example

A game abandoned at 70% completion remains mentally represented with a known ending and unexplored areas that still matter to the player.

### Research example

A theory has enough structure that the unresolved contradiction keeps reappearing as a live object of thought.

### Borderline example

A book sits unread on a shelf but is never thought about. It is unfinished, but not necessarily open in the cognitive sense.

## Non-examples

A forgotten abandoned object is not an open object merely because it was never completed.

A future aspiration with no bounded object or represented remainder may be desire, but not this concept.

## Boundaries and failure modes

“Open” should not imply pathology or obligation. Many open objects are harmless or useful.

The object can also close without formal completion if the person deliberately abandons the relation or no longer values the remainder.

## Operationalization / evidence

Look for spontaneous recall, identifiable remaining structure, residual value, and a sense that the relation is still unfinished.

A useful test is: **If reminded of the object, does the person experience it as something still in progress, or merely something that once happened?**

## Relations

Open objects enable **Closure pressure**, contain an **Absorption remainder**, and can be closed by **Deliberate closure** without necessarily being technically completed.
