# Expressive animation

## Definition

**Expressive animation** treats motion as information.

A character's visible movement should carry evidence about:

- intent;
- urgency;
- effort;
- hesitation;
- emotion;
- attention;
- confidence;
- social stance.

Animation therefore becomes part of the simulation's epistemic channel.

## Problem pressure

The term emerged because “emotion systems” often terminate in cosmetic emotes.

The character has fear = 0.8, so the face plays “fear.”

That is too shallow.

If fear matters causally, it should affect:

- approach distance;
- speed;
- gaze;
- posture;
- interruption;
- motor precision;
- willingness to remain nearby.

Other agents can then infer fear from behavior.

## Core model

```text
internal state
      ↓
decision / motor intent
      ↓
expressive modulation
      ↓
visible movement
      ↓
social perception
```

Animation is not merely a display layer.

It is the **public surface of internal causality**.

## Non-telepathic value

Without expressive behavior, agents have little evidence from which to infer each other's state.

Thus expressive animation and non-telepathic social inference are complementary.

## Non-examples

Expressive animation is not:

- playing more emotes;
- cinematic animation quality;
- facial animation alone;
- scripted acting disconnected from agent state.

## Failure modes

### Emote substitution

Complex emotion becomes one canned gesture.

### Signal determinism

Every emotion has one perfectly readable visual code, eliminating ambiguity.

### Cosmetic modulation

Animation changes while decisions remain identical.

### Social irrelevance

Other agents never perceive the expression.

## Operationalization

Ask:

> If the internal state changed, would a careful observer have some chance of detecting that change from behavior?

Not perfect certainty—just evidence.

## Provenance
