# narrator information set

## Definition

A **Narrator information set** is the information a narrator is legitimately positioned to access at a given point in a story.

It may include:

- direct perception;
- memory;
- testimony;
- documents;
- recordings;
- archives;
- inference from known evidence;
- retrospective knowledge acquired later.

The information set answers:

> **What could this narrator have access to?**

It does **not** answer:

> What is actually true?

or:

> What does the narrator believe?

Those belong to **Diegetic truth** and **Epistemic state** respectively.

## Problem pressure

The Great Subjectification entry uses narration as a central example of turning an unexplained voice into **a narration from a position carrying a bounded information set**.

The Epistemic chain of custody entry likewise argues that once narration is positioned, access itself becomes analyzable.

The missing term was the explicit container for that access boundary.

## Core model

~~~text
diegetic world
      ↓ through channels
perception / records / testimony / memory
      ↓
NARRATOR INFORMATION SET
      ↓ interpreted into
epistemic state
      ↓
narrative report
~~~

## Claims and implications

An information set can be large without being omniscient.

A retrospective narrator may know later consequences but still lack access to another character’s private thoughts.

The concept also distinguishes **access error** from **reasoning error**:

- missing clue → information-set limitation;
- clue available but misread → epistemic-state failure.

That separation improves narratological precision.

## Examples

### First-person narrator

A character can report what they saw and later learned but not an unseen private conversation unless the story supplies a transmission route.

### Recovered manuscript

The editor-narrator’s information set consists of the surviving manuscript plus external records used to annotate it.

### Historical narrator

A narrator may know events only through archives, giving the archive itself a structural role in what can be said.

## Non-examples

Everything the author knows is not automatically part of the narrator information set.

A narrator’s false belief is also not an information-set element merely because the narrator asserts it.

## Boundaries and failure modes

Narrative convention may permit access that is not realistically modeled, especially in free indirect discourse or omniscient narration.

The concept should not be used to declare such techniques “invalid.” It is most useful when a work makes access conditions salient or when the analysis specifically concerns epistemic grounding.

## Operationalization / evidence

For each narrated claim, ask:

1. what channel provides access?
2. when did the narrator acquire it?
3. what transformations occurred?
4. could the narrator distinguish source from inference?
5. is the reported detail inside or outside the modeled set?

## Relations

Narrator information set operationalizes **Diegetization**, shapes a narrator’s **Epistemic state**, is distinguished from **Diegetic truth**, and supports **Epistemic chain of custody** by making access links explicit.
