# Tarium Meta Artifacts

`meta/` contains load-bearing cross-repository institutional artifacts that are neither ordinary concept entries nor repository entities.

The initial canonical pair is:

- [`Tarium Procedure`](tarium-procedure.md) — the epistemic constitution;
- [`Tarium Register`](tarium-register.md) — the default institutional prose realization of that constitution.

These artifacts are intentionally outside the ordinary concept promotion queue.

They describe shared operating structure of the Tarium ecology itself.

## Ownership

Conceptarium is the canonical home for these cross-domain definitions because their deepest ontology is meta-epistemic and institutional.

Other repositories may realize, specialize, analyze, or decline them locally without Conceptarium acquiring governance authority over those repositories.

See [`docs/TARIUM_ECOLOGY.md`](../docs/TARIUM_ECOLOGY.md).
