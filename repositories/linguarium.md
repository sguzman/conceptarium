# Linguarium

## Predicate identity

- **Repository:** `sguzman/linguarium`
- **Family status:** core Tarium member
- **Role:** domain repository
- **Broad domain:** language cataloguing and learning, including vocabulary, etymology, syntax, dialects, language families, and writing systems

## External classification

Linguarium is the Tarium repository dedicated to language as both an object of cataloguing and a domain of learning infrastructure.

Conceptarium may model cross-domain concepts that touch language, but Linguarium remains the canonical home for Linguarium's own language objects and learning structures.

## Conceptarium knowledge boundary

Conceptarium records Linguarium's existence, coarse purpose, and explicit cross-repository relations.

It does not mirror vocabulary inventories, language objects, dialect state, learning progress, or internal artifacts by default.

## Authority boundary

Linguarium is authoritative for its own language ontology and artifacts.

Conceptarium's description remains an external projection.
