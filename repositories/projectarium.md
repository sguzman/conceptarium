# Projectarium

## Predicate identity

- **Repository:** `sguzman/projectarium`
- **Family status:** core Tarium member
- **Role:** inventory repository
- **Broad domain:** a minor ontology and inventory of GitHub projects and project-level state

## External classification

Projectarium is the Tarium repository for maintaining an inventory-level view of the user's project ecology.

Its ontology is intentionally more operational and inventory-oriented than the larger theory repositories.

## Conceptarium knowledge boundary

Conceptarium records Projectarium's existence, broad role, and any explicitly declared cross-repository relation.

It does not inherit Projectarium's live project inventory, project status, compliance state, queue, or artifact details by default.

## Authority boundary

Projectarium is authoritative for project-level inventory and state.

Conceptarium may theorize about Projectarium as a type of repository without becoming a second project tracker.
